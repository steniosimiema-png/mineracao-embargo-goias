# Mineração x Embargo Ambiental — Goiás

Mapa web interativo cruzando processos minerários (ANM/SIGMINE) e áreas de embargo ambiental (SEMAD-GO), com foco em terras raras e minerais estratégicos.

**Autor:** Stênio Simiema — Drones e Mapas
**Fontes:** ANM/SIGMINE, SEMAD-GO (SIGA), IBGE 2022 · SIRGAS 2000 / WGS84
**Tecnologia:** QGIS + Leaflet

Acesse o mapa: abra o index.html ou a página publicada via GitHub Pages.
